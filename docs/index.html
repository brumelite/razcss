Le CSS, sur des bases saines.

RazCSS est un reset CSS léger et sans dépendances. Il harmonise quelques comportements du navigateur sans imposer de design à votre projet.

01 / Démarrer

Deux façons de l'utiliser.

Copiez la commande qui correspond à votre projet.

Avec npm

Voir sur npm ↗

Pour un projet utilisant npm et un bundler compatible avec les imports CSS (comme Vite).

npm install @brumelite/razcss
import '@brumelite/razcss/dist/reset.css';

Avec un CDN

Voir le CSS ↗

Ajoutez une balise dans le <head> de votre page HTML.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@brumelite/razcss@1.0.1/dist/reset.css">

Version minifiée automatiquement par jsDelivr :

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@brumelite/razcss@1.0.1/dist/reset.min.css">

Les URL CDN ciblent la version 1.0.1 : le rendu reste stable même lorsqu'une nouvelle version est publiée. La variante minifiée est fournie par jsDelivr, et non par le package npm.

Les différences peuvent être discrètes : RazCSS conserve volontairement les styles natifs utiles. Les listes classiques gardent leurs puces ; les listes marquées role="list" sont dépourvues de puces et d'espacement.

03 / Le projet

Minimaliste par choix.

RazCSS pose quelques fondations : box-sizing: border-box, suppression de certaines marges natives, médias adaptatifs et typographie héritée par les contrôles de formulaire.

Il ne remplace pas une feuille de style complète et ne prétend pas rendre tous les navigateurs identiques. Son code reste court, lisible et facile à adapter.
